# TerraAlert AI

AI-powered disaster risk prediction and decision-support platform for flood and landslide management.

## Overview

TerraAlert AI integrates radar, satellite, weather, terrain, and historical disaster data to provide AI-based disaster risk assessment and decision support for disaster management authorities.

## Architecture

TerraAlert AI follows a microservice-based architecture.

### Backend

- Java
- Spring Boot
- MongoDB
- REST APIs

### AI/ML

- Python
- Machine Learning
- Deep Learning

### Frontend

- React
- TypeScript

### Infrastructure

- Docker
- Redis
- RabbitMQ

## Microservices

- API Gateway Service
- Auth Service
- Data Ingestion Service
- Data Processing Service
- AI Prediction Service
- Risk Assessment Service
- Geospatial Service
- Alert Management Service
- Shelter & Resource Service
- Evacuation Service
- Notification Service
